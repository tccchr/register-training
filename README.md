# Register Training

Internal training registration portal for TCCC Learning LAB.

## What It Does

- Employees sign in with Microsoft 365, browse eligible courses, reserve class seats, and view their training calendar.
- Approvers manage participant assignment for courses that require approval or team-level control.
- Admins create courses, manage classes, review rosters, export registration data, and maintain employee access.

## Tech Stack

- Vite
- React
- Tailwind CSS
- Supabase
- Microsoft 365 OAuth

## Scripts

```bash
npm run dev
npm run lint
npm run build
```

The app is served under `/register-training/` in production.
